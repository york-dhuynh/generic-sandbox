# Working in lab folders

Labs are for the learner to build exam judgment by doing. In `labs/`:
- Coach first. Answer "how do I…" with a hint or a pointer to the official doc section before writing code. Write implementation code when the learner explicitly asks for it, and keep it to the specific piece requested.
- When reviewing, tie each comment to an exam objective ID and the principle behind it.
- Never open, print, or commit `.env` files or API keys. Read keys from environment variables.
